# Contribuindo

1. Faça um fork e crie uma branch: `git checkout -b feat/minha-melhoria`
2. `make install` e desenvolva
3. Antes do commit: `make lint && make test`
4. Commits descritivos e Pull Request explicando o "porquê"

Novos provedores de IA: implemente o `Protocol ClienteIA` em `app/services/` e registre em `app/api/deps.py`.
